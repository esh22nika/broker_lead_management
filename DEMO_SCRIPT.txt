WEEK 7-8: JENKINS CI/CD PIPELINE
====================================================================

WHAT I DID:
- Installed Jenkins on port 8080 with Git, Maven, Pipeline plugins
- Connected Jenkins to the GitHub repository
- Created a declarative Jenkinsfile with 6 stages:
  1. Checkout    - pulls code from GitHub
  2. Build Backend  - mvn clean compile -DskipTests
  3. Unit Tests     - mvn test (runs 20 JUnit + integration tests)
  4. Package        - mvn package -DskipTests (creates JAR)
  5. Build Frontend - npm install && npm run build
  6. Selenium Tests - mvn test -Pselenium (non-blocking, yellow on fail)
  7. Deploy         - only runs on main branch
- Configured Jenkins tools: Maven-3.9.16 and JDK-21
- Used bat commands (Windows environment)
- Build artifacts archived: blms-backend.jar and frontend dist/
- Deploy stage skips on develop branch (only deploys from main)

JENKINSFILE KEY FEATURES:
- catchError(buildResult: 'SUCCESS', stageResult: 'UNSTABLE')
  wraps Selenium stage so failing Selenium doesn't fail the whole build
- junit plugin publishes test reports for trend tracking
- archiveArtifacts saves the JAR and frontend build
- cleanWs() in post block cleans workspace after each run

HOW TO START THE APP FOR LIVE DEMO
====================================================================

1. Start PostgreSQL (should already be running as a service)

2. Start backend (from project root):
   cd backend
   mvn package -DskipTests
   java -jar target\blms-backend.jar
   (Backend runs on port 8081)

3. Start frontend (new terminal, from project root):
   cd frontend
   npm run dev
   (Frontend runs on port 5173)

4. Open browser: http://localhost:5173

5. Demo credentials:
   Admin:   admin@blms.com   / admin123
   Manager: manager@blms.com / manager123
   Broker:  broker@blms.com  / broker123
